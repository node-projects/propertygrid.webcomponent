Layout — apply separately in JavaScript

        

        
Layout (row height, column share, header and description visibility) remains active when Theme is off; only appearance variables and part rules are removed. Use rowHeight and nameColumnRatio, not CSS row heights or column widths. Fonts, editor padding, borders and focus outlines must fit inside the fixed row; multiline rows are not supported. Editors are vertically centered by default. Editor height is optional: Auto keeps native sizing and never stretches checkboxes/radios. Optional inline padding, hierarchy indent, height, native separator styles and nested focus borders require CSS container style-query support (current Chromium); missing tokens preserve original spacing and sizing.
